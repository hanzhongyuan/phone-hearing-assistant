## 2. 骨传导解释与校准前提

骨传导刺激可通过颅骨到达两侧耳蜗。软件选择“左声道”并不证明只刺激左耳；未经合适掩蔽的结果不能标为独立左耳/右耳临床骨导阈值。软件图表如保留左右标签，只表示输出声道/主观响应。感到振动不等于听到声音，尤其低频应分别记录。[ASHA 骨导说明](https://www.asha.org/practice-portal/clinical-topics/hearing-loss)、[ASHA 听力图符号说明](https://www.asha.org/policy/GL1990-00006/)

手机测出的 dBFS 不可换算成 dB HL、dB SPL 或骨导振动力等级。临床骨导与气导测量使用适当校准换能器及相应测量装置；普通耳道声压计也不能完整测量骨导刺激。专业人员应评估骨导换能器所需的机械耦合/人工乳突或适配测量装置、佩戴力和频率响应。未经这种验证，不给出本组合的声压安全上限或暴露剂量结论。[BSA 现行指南入口及纯音程序](https://www.thebsa.org.uk/guidance-and-resources/current-guidance/?resource=recommended-procedures)

## 3. 先完成无需佩戴的工程检查

1. 核对 APK 校验和、来源和版本。先安装而不启动助听；检查录音权限的拒绝、授予和撤销行为。
2. 将系统媒体音量降至零，连接耳机，确认实际输出设备；从应用启动/停止，确认不会自动把系统音量调大。
3. 耳机不佩戴，检查断开蓝牙、来电/音频焦点变化、切换模式、锁屏/后台、重新进入应用。助听应停止或明确暂停，不能在路由丢失后继续通过手机扬声器放大。
4. 检查紧急停止按钮；等待中的 TTS、纯音和音频队列都应停下。再次启动应保持保守设置。
5. 用合适测试设备检查输出突变、爆音、NaN/溢出、重启后的残留音频。增益上限和限幅单元测试通过只能证明数字行为，不能替代真实输出校准。

如任何项失败，先反馈日志与复现步骤并修复，不进入佩戴测试。

## 4. 初次佩戴：低音量短时技术试用

由能立即操作停止的另一位成年人陪同，在安静房间坐着进行。不要在驾驶、道路活动、使用机器或需依赖报警声的场景尝试。试用者应知道这是未完成校准与效益验证的工程版本，可以随时停止，不以听到极高频或微弱声音为目标。

从系统媒体音量零开始，增益维持最低设置；按单个音量步进，仅增加到轻柔且舒适的水平。若未听到，不以持续增大音量寻找听觉上限。首轮每个模式仅短暂试听，间隔休息；时间安排只是限制操作负担，并非已测得的安全剂量。发生疼痛、不适、眩晕、耳鸣加重、明显振动或突发啸叫立即停止并摘下耳机；持续症状应由听力/耳科专业人员评估。

有突然或近期明显听力变化、耳痛/耳部症状，或无法可靠表达不适的情况，先进行专业评估。儿童、重度听损或声音耐受异常人群不作为未经校准版本的首次技术试用对象。骨传导绕过部分外/中耳传导路径，不能据此认为能纠正所有感音神经性听损。

## 5. 相对听感测试

目的仅为同一设备、同一音量与佩戴条件下记录不同频率的主观可听性。

1. 先停止助听、TTS 与增强；保存设备、系统音量和耳机 EQ。
2. 从低幅度短纯音开始；有听到、没听到和停止选项。不要用“猜测听到”或感到振动代替听觉响应。
3. 到达应用允许上限仍未听见，保存“在本次范围内无响应”。中途停止记为未完成。二者不能当成一个确切高阈值，更不能推断“耳聋等级”。
4. 随机/交错加入不发声时段，可检查按键习惯；如应用版本未实现，操作者应只作为外部观察记录，不伪称软件已做可靠性检验。
5. 在同一设备链路重复若干频率。结果不稳定时先检查环境、佩戴与路由，不自动提高增益。
6. 骨导模式可观察各输出声道响应，但不据此设计对侧掩蔽或诊断双耳差异；这些由专业测听完成。

临床 dB HL 图如由听力中心提供，应保留测量日期、气导/骨导、掩蔽情况和原始单位。它与本应用相对听感图分别保存，不相互覆盖。

## 6. 三个模式的比较方法

在相同手机位置、讲话距离、环境与舒适音量下，按轮换顺序比较。不同条件用不同但难度相近的短句，避免先看字幕或记住句子使听辨结果虚高。

| 条件 | 观察内容 | 失败或停止条件 |
|---|---|---|
| 无处理/最低增益基线 | 原始清晰度、舒适度、背景声 | 本身不舒适则不继续 |
| 模式1 频段补偿 | 词语正确率、是否更费力、是否放大噪声 | 明显失真、啸叫、过响 |
| 模式2 频率映射 | 辅音/元音辨认、语调变化、是否“听到但听不懂” | 理解下降、怪异音或负担明显 |
| 模式3 字幕 | 字错、漏字、中文专名/数字、延迟 | 错误文字被误当可靠指令 |
| 模式3 可选重述 | 句末到播报耗时、断句、重复播报、声音舒适 | 自识别循环、排队越积越长或长时间无法停止 |
| GTCRN vs DPDFNet vs 关闭 | 弱音被删、语音自然度、计算掉音 | 清晰度反而下降或手机过热 |

模式2 的全部频带压缩/搬移可能损失语音细节；仅“听到了更多声音”不代表理解改善。模式3 的 ASR/TTS 延迟和原话错误要单独记录，不能混进实时直听延迟。若播报期间暂停录音，要记录漏掉的同时讲话。

第一轮保持环境简单；之后才在可控低背景声下比较，不能通过提高外放噪声或耳机音量模拟危险暴露。不得用本版本的字幕/重述作为医疗、紧急报警、用药或交通信息的唯一来源。

## 7. 延迟、稳定性和隐私记录

- 端到端延迟应从输入事件到耳机实际输出测量。气导可用适当双通道录音/回环；骨导需适当机械拾取装置。屏幕刷新时间、模型耗时和猜测的蓝牙 codec 延迟不能替代完整测量。
- 分别记录启动、连续运行、屏幕关闭和来电恢复的路由；记录音频 underrun、温度和电量变化。长时间测试先以无需佩戴方式运行。
- 试用期间无需保存原始会话。若主动录音用于调试，须让所有被录者知情，明确保存位置与删除方式；分享日志先移除姓名、真实字幕和健康资料。
- 应用崩溃、蓝牙断开、TTS出错或字幕停滞，保存时间、模式、设置和复现步骤；不要通过持续增加增益“修复”软件问题。

## 9. 单侧先测、双侧联调补充步骤

按“左输出声道 → 右输出声道 → 双声道一起”顺序执行相同的低幅度相对听感流程。每个条件独立保存完整/未完成/无响应状态及系统音量。双声道条件需要重新作答和记录，不能以两侧数据平均值替代测量；其舒适音量也不应预设等于单侧。

随后在双声道实际使用条件下，对模式1补偿、模式2映射与模式3播报重新试听。调节从低音量开始，保持输出限制；记录左右平衡偏好、双侧总响度和言语清晰度。骨传导头戴设备的左右换能器通过颅骨耦合，所谓“单侧”仅指软件输出声道选择，不是耳蜗隔离。不得凭本流程判定单侧耳聋、左右骨导差异或替代掩蔽测听。
